Portfolio Website

A modern, responsive personal portfolio website built with React, featuring smooth animations, clean UI design, anchor-link smooth scrolling, and sections for projects, skills, experience, and contact information.

✨ Features

🌟 Modern & Responsive UI
⚛️ Built using React
🎨 Styled with custom CSS
🔗 Smooth scrolling using react-anchor-link-smooth-scroll
📂 Project showcase section
🧩 Skills, Experience & Education
📞 Contact form
📄 Resume download button
🚀 Fast performance, clean layout

🛠️ Tech Stack

React.js
HTML5, CSS3
JavaScript (ES6+)
Anchor Link Smooth Scroll
W3forms(for email)
